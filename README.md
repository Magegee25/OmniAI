# OmniAI

Description: A personal AI coding assistant powered by a hybrid architecture of local and cloud-based LLMs. By integrating locally hosted AI models with FreeLLMAPI by tashfeenahmed, the system combines unlimited local computing capabilities with access to approximately 1.7 billion tokens per month from cloud-based models, delivering a powerful, flexible, and cost-efficient AI development companion.

## Features

- Local LLM support
- FreeLLMAPI integration
- Codebase understanding
- File manipulation
- Terminal execution
- VS Code integration
